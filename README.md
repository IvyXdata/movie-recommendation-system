MOVIE RECOMMENDATION SYSTEM

PROJECT OVERVIEW

This project explores movie recommendation and rating prediction using machine learning techniques. It was developed as part of the Kaggle Movie Recommendation Hackathon 2026.

OBJECTIVES

Explore and understand movie rating data.

Perform data cleaning and preprocessing.

Analyse user and movie rating patterns.

Develop machine learning models.

Evaluate model performance using Root Mean Squared Error (RMSE).
